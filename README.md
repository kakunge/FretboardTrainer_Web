# Fretboard Trainer
기타 지판에서 음의 위치를 익히는 웹 앱입니다. 표준 튜닝(E–A–D–G–B–E)을 기준으로 개방현부터 12프렛까지, 같은 음의 옥타브 위치와 자연음 배열을 살펴보고 퀴즈로 연습할 수 있습니다.

[GitHub Pages에서 시작하기](https://kakunge.github.io/FretboardTrainer_Web/)

## 훈련 모드
| 모드 | 연습 방법 |
| --- | --- |
| 옥타브 도형 시각화 | 4도권에서 음을 선택하고, 줄을 옮길 때 같은 음이 어디에 나타나는지 확인합니다. **수직 옥타브 듣기**로 표시된 음을 순서대로 들을 수 있습니다. |
| 자연음 랜드마크 | 지판에서 C, D, E, F, G, A, B를 찾습니다. **E–F / B–C 반음 강조**를 켜서 반음 위치를 확인할 수 있습니다. |
| 인레이 세로줄 기준 | 3, 5, 7, 12프렛 중 하나를 선택해 6번 줄부터 1번 줄까지의 음 배열을 확인합니다. |
| 지판 인출 퀴즈 | **음 → 프렛**에서는 지정한 줄에서 해당 음을 누릅니다. **프렛 → 음**에서는 표시된 위치의 음 이름을 고릅니다. |
| 계이름 ↔ 알파벳 | 도·레·미와 C·D·E 사이를 양방향으로 변환해 봅니다. 랜덤 혼합과 임시표(♯/♭)를 선택할 수 있습니다. |
| 기타 입력 4도권 | 아무 줄에서나 C부터 4도권 12음을 한 음씩 피킹합니다. 목표음이 감지되면 다음 음으로 진행합니다. |

상단의 **소리** 버튼으로 기타 음을 켜거나 끌 수 있습니다.

### 오디오 인터페이스 연결

기타를 오디오 인터페이스의 악기 입력에 연결합니다. HTTPS 또는 localhost에서 **6. 기타 입력 4도권 → 입력 시작**을 누르고 브라우저의 오디오 입력 권한을 허용합니다. **입력 장치**에서 오디오 인터페이스를, **입력 채널**에서 기타를 연결한 채널을 선택합니다. **감지한 음 표시**를 끄면 목표음과 진행도만 보면서 연습할 수 있습니다.

## 모바일 홈 화면에 추가
- **iPhone Safari**에서 사이트를 열고 **공유 → 홈 화면에 추가**를 선택합니다.
- **Android Chrome**에서 사이트를 열고 **⋮ → 홈 화면에 추가**를 선택합니다. 브라우저에 따라 **앱 설치**로 표시될 수 있습니다.

## 로컬에서 실행
- 저장소를 클론한 뒤 Python 3의 내장 HTTP 서버로 실행할 수 있습니다.

```sh
git clone https://github.com/kakunge/FretboardTrainer_Web.git
cd FretboardTrainer_Web
python3 -m http.server 8000
```

- 브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다. 앱은 HTML, CSS, JavaScript로 구성되어 있으며 패키지 설치나 별도 빌드가 필요 없습니다.
